Presentación de Algoritmo & Análisis de Datos

Este proyecto demuestra el procesamiento eficiente de grandes conjuntos de registros utilizando la técnica clásica de Corte de Control (Control Break) en lenguaje ANSI C. Originalmente desarrollado para la materia Algoritmos y Programación I (FIUBA), ha sido optimizado y dotado de una interfaz interactiva moderna.

Arquitectura de Archivos del Proyecto

El código fuente se divide modularmente siguiendo buenas prácticas de ingeniería de software en C:

main.c / main.h

Punto de entrada. Maneja los argumentos de la línea de comandos (`-in` y `-out`), apertura y cierre de archivos, e invoca al procesador.

control.c

Contiene la lógica de la máquina de estados del Corte de Control (`cortes_de_control`) y las rutinas de ruptura por país y mes.

input.c

Analizador léxico. Lee y procesa las líneas del CSV (delimitadas por comas), deserializando la marca de tiempo Unix y los casos.

names.c / names.h

Encargado del mapeo de países. Lee directamente desde el archivo indexado binario `names.bin` buscando el offset `code * 150 - 1` con `fseek` para evitar cargar grandes bases de datos en RAM.

Sistema de Construcción Robusto

El proyecto incluye un Makefile moderno que compila con estándares estrictos y optimizaciones:

CC = gcc
CFLAGS = -Wall -Wextra -Werror -std=c99 -pedantic -O2
TARGET = analisis_covid

all: $(TARGET)

$(TARGET): $(OBJS)
	$(CC) $(CFLAGS) $(OBJS) -o $(TARGET)

Cómo compilar y ejecutar en tu terminal

Clona el repositorio y sigue los siguientes comandos:

# 1. Clonar el repositorio
git clone https://github.com/dayher/analisis_covid.git
cd analisis_covid

# 2. Generar el archivo binario indexado names.bin desde el CSV
python3 scripts/generate_names.py

# 3. Compilar el programa C
make

# 4. Ejecutar indicando la entrada y la salida
./analisis_covid -in data.csv -out output.txt

# 5. Ver los resultados procesados
cat output.txt
